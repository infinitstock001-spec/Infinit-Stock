Cargá tus videos

Subí cada clase a YouTube como "no listado" (o a Vimeo), copiá el ID y pegalo acá. Se guarda en este navegador para que puedas probar al toque. Cuando esté todo cargado, exportás abajo y pegás el resultado en js/data.js para que quede publicado para todos.

⚠️ Esta página no tiene contraseña.

No guarda datos sensibles ni permite cobrar, pero conviene no compartir el link. Si querés protegerla de verdad, en Netlify se hace con password protection o con una regla en _headers.

Exportar los videos cargados

Copiá este bloque y pegalo al final de js/data.js, reemplazando el bloque anterior si ya existe. Así los videos quedan publicados para todos los alumnos, no solo en tu navegador.
